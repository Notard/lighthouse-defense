# 테스트 표 쓰는 법 (리드)

tester가 이 표를 **그대로** Dart 테스트로 옮긴다. 기대값은 표가 정답이다.

```markdown
# <기능> 테스트 표

| 번호 | 주어진 것 | 행동 | 기대값 |
|---|---|---|---|
| T2-01 | 새 판 | 아무것도 안 함 | 등대 둘레 안쪽 자리 6개, 바깥 자리 12개 |
| T2-02 | 새 판 | 등대 오른쪽(1000, 660)을 향해 끈다 | 빛 방향 0° (±1°) |
```

- 번호: `T<단계>-<두 자리>`. 테스트 이름에 그대로 들어간다
- 기대값은 숫자와 허용 오차를 적는다. "적당히", "빨리" 같은 말은 쓰지 않는다
- 화면 모양처럼 테스트로 판정할 수 없는 것은 테스트 표가 아니라 인수 조건(`docs/acceptance/`)에 "사용자 확인"으로
